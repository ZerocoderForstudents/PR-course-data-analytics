*В рамках проекта был проведён A/B-тест, направленный на оценку эффективности нового расположения первого рекламного блока в приложении маркетплейса. Вместо текущего размещения в ленте товаров, блок был перенесён над основной секцией. Цель эксперимента заключалась в проверке гипотезы о том, что новое расположение увеличит вовлечённость пользователей, повысит кликабельность (CTR) и улучшит конверсионные показатели.

Подготовительный этап включал анализ пользовательского поведения до начала эксперимента, визуализацию ключевых метрик (CTR, конверсии, средний чек), а также построение воронки взаимодействия с рекламой. Затем был разработан дизайн эксперимента: определены основные и вспомогательные метрики, рассчитан минимальный наблюдаемый эффект (MDE), а также определён необходимый размер выборки с учётом ограничений — охват не более 20% пользователей в течение недели.

После завершения теста были сопоставлены показатели контрольной и тестовой групп, выполнена оценка статистической значимости различий, а также проведён дополнительный анализ поведения пользователей. Эти шаги позволили выявить влияние изменения размещения рекламного блока на пользовательскую активность и ключевые бизнес-метрики.

Проект реализован с использованием SQL (обработка данных, построение воронок), Python и библиотек pandas, numpy, matplotlib, seaborn (анализ и визуализация), Jupyter Notebook (документирование), а также GitHub (хранение кода и отчётов). На основании полученных данных даны рекомендации по внедрению нового расположения блока, подтверждённые статистически значимыми результатами эксперимента.
